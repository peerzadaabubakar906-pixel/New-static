# Doc QA Checker (Vercel)

Folder structure:
- public/index.html  -> page (link box)
- api/check.py       -> checks (Python function)

Deploy: is folder ko GitHub repo ke root mein upload karein, phir Vercel mein "Import Project".
Optional password: Vercel > Settings > Environment Variables > ACCESS_KEY = apna password, phir Redeploy.
